# Data and licences

## Fixtures (`data/fixtures/`)

All fixture data was written for this project and is **synthetic**: every issuer,
ticker, identifier, headline and URL is invented. It is dedicated to the public domain
(CC0-1.0). Any resemblance to a real company or ticker is coincidental and must not be
relied on. Source URLs use the reserved `.invalid` top-level domain, so none of them
resolve.

| File | Contents |
|---|---|
| `instruments.json` | 8 fictional issuers with effective-dated listings, including a ticker change (VIRE → VRCS on 2026-03-09) and a shared alias ("Apex"). |
| `news/seed.jsonl` | 18 hand-written lines, one per behaviour to exercise (table below). |
| `news/replay.jsonl` | 121 items generated by `scripts/generate_fixtures.py` from a fixed seed: templates, a Markov "tone" per issuer, cross-wire copies and late arrivals. |
| `MANIFEST.json` | SHA-256 of each file (over LF-normalised bytes). Tests fail if a file drifts. |

Nothing measured on this data says anything about real markets.

## Sentiment lexicon

The word lists in `services/sentiment/.../lexicon.py` were written for this project and
are deliberately small. The Loughran–McDonald dictionary is the standard reference for
finance, but it is **not bundled**: its terms allow academic use and restrict
redistribution and commercial use. A licensed copy could be added locally without
committing it.

The baseline is easy to fool. The injected sentence in seed line 14 raises its score, and
a test pins that weakness so it is never mistaken for robustness.

## Real data

No real market data, news or filings are used or committed. Adapters for permitted
sources (SEC EDGAR within its access policy) start in M1, with provider terms recorded
here before any data is fetched.
