# Data and licences

## Fixtures (`data/fixtures/`)

All fixture data was written for this project and is **synthetic**: every issuer,
ticker, identifier, headline and URL is invented. It is dedicated to the public domain
(CC0-1.0). Any resemblance to a real company or ticker is coincidental and must not be
relied on. Source URLs use the reserved `.invalid` top-level domain, so none of them
resolve.

| File | Contents |
|---|---|
| `instruments.json` | 8 fictional issuers with effective-dated listings, including a ticker change (VIRE → VRCS on 2026-03-09) and a shared alias ("Apex"). |
| `news/seed.jsonl` | 18 hand-written lines, one per behaviour to exercise (table below). |
| `news/replay.jsonl` | 121 items generated by `scripts/generate_fixtures.py` from a fixed seed: templates, a Markov "tone" per issuer, cross-wire copies and late arrivals. |
| `MANIFEST.json` | SHA-256 of each file (over LF-normalised bytes). Tests fail if a file drifts. |

Nothing measured on this data says anything about real markets.

## Sentiment lexicon

The word lists in `services/sentiment/.../lexicon.py` were written for this project and
are deliberately small. The Loughran–McDonald dictionary is the standard reference for
finance, but it is **not bundled**: its terms allow academic use and restrict
redistribution and commercial use. A licensed copy could be added locally without
committing it.

The baseline is easy to fool. The injected sentence in seed line 14 raises its score, and
a test pins that weakness so it is never mistaken for robustness.

## Real dataset (`data/real/`)

What the dashboard, the Vercel snapshot and `make demo` show. Captured from SEC EDGAR by
`scripts/capture_edgar.py` (`make capture`) for 40 large US companies and the five Indian
companies that file with the SEC (Infosys, HDFC Bank, ICICI Bank, Wipro, Dr. Reddy's),
for 1 January to 23 October 2026.

| File | Contents |
|---|---|
| `instruments.json` | Each company's name, SEC CIK (the stable instrument ID, `SEC-<CIK>`), SIC industry and ticker, all from EDGAR. The Indian companies keep their NSE symbols and `NSE-` IDs. |
| `news/edgar.jsonl` | One line per 8-K (US) or 6-K (foreign private issuer) filing: the headline of its press release or exchange letter (or the 8-K items it reports), an excerpt of at most 1,200 characters, the EDGAR acceptance time, and the filing's URL on sec.gov. |
| `MANIFEST.json` | SHA-256 of each file (LF-normalised); a test fails if a file drifts. |

**Terms.** EDGAR filings are public records filed with a US government agency; the
download followed the SEC's fair-access policy (declared User-Agent, at most 8 requests a
second). The text inside a filing (a press release, an exchange letter) is written by the
company. The dataset quotes only a headline and a short excerpt of each, always with the
link to the full filing, for research and education. No prices are included.

**Timing.** `published_at` and `first_seen_at` are the EDGAR acceptance time, because
EDGAR disseminates a filing when it accepts it; this is a backfill from the archive, so
the feed is labelled **delayed**, not live. A live poller would record its own clock.

**Headlines are extracted by rules**, not written by hand: the first title-like line of
the press release, the subject line of an exchange letter, or the 8-K items the filing
reports. Some are imperfect (a wrapped title cut short, a generic "Other events"); every
item links to its source.

Reliance, TCS and Sun Pharma, which were in the earlier NSE reference list, do not file
with the SEC and have no permitted news source here, so they are not in this dataset.

## Dashboard snapshot

`web/src/data/snapshot.json` is the pipeline's output over the real dataset above,
exported by `scripts/export_snapshot.py`, so the same terms apply. The synthetic fixtures
remain the basis of the deterministic tests and of `make up && make seed && make smoke`.

## Real data (the earnings study)

The live pipeline and its fixtures still use no real data. The offline earnings study
(`research/src/alphadots_research/earnings`, plan in
[`research/earnings-tone-preregistration.md`](research/earnings-tone-preregistration.md))
downloads real data with `make earnings-data` into `var/research/`, which is gitignored.
**No raw real data is committed.** What is committed is `web/src/data/earnings-study.json`
and the generated report: statistics over thousands of events (regression coefficients,
averages by tercile, portfolio returns), never a single stock's prices or a release's text.

| Source | What | Terms, and how the project complies |
|---|---|---|
| SEC EDGAR (`data.sec.gov`, `www.sec.gov`) | Submissions, 8-K filing indexes and EX-99 press releases, XBRL frames | US government works, no copyright. The [fair-access policy](https://www.sec.gov/os/accessing-edgar-data) asks for a declared User-Agent with a contact and at most 10 requests per second. The downloader sends `ALPHADOTS_SEC_USER_AGENT` (set in `.env`, never committed) and stays at or under 8 per second across all threads. |
| Yahoo Finance chart endpoint | Daily split- and dividend-adjusted closes | **Not licensed for automated download or redistribution.** Used at the project owner's explicit choice (2026-10-26) instead of a free licensed key. Kept on the local machine, rate-limited to one request per second, never redistributed; a persistent 429 stops the download. Replace `daily_bars` with a licensed provider (for example Tiingo, Polygon or CRSP via WRDS) before any other use. |
| Kenneth R. French data library | Daily market, FF5 and momentum factors | Free for research with citation: Fama and French (2015), Carhart (1997). |
| Loughran-McDonald Master Dictionary 1993-2025 | Positive and negative word lists | Free for academic research; commercial use needs a licence. Downloaded at run time from the authors' link, never committed. Cite Loughran and McDonald (2011). |

Price history exists only for firms still listed, so 61 of the 300 selected firms have
no prices; the report counts them and treats the result as a statement about survivors.
